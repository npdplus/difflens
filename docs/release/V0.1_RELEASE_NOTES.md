# DiffLens v0.1.0 Release Notes

DiffLens v0.1.0 is the first public release of the local-first structured-data comparison workflow.

## Highlights

- Compare CSV, XLSX, JSON, and YAML in the browser.
- Explicitly select the record key and optionally ignore fields.
- See deterministic Added, Removed, Changed, and Unchanged classifications.
- Inspect field-level Before/After differences for Changed records.
- Filter and search results without changing comparison semantics.
- Export a deterministic CSV report locally with spreadsheet formula-injection mitigation.
- Try synthetic examples through the same parsing, validation, comparison, results, and export pipeline.
- Use light or dark mode; only the theme preference is persisted.

## Privacy and security

The core V0.1 workflow does not require a backend upload. Source contents, normalized data, comparison results, and report data stay in the browser during representative release verification flows.

Imported values are treated as untrusted data and rendered inertly. Spreadsheet formulas/macros are not executed, external workbook links are not followed automatically, and exported formula-like cells are neutralized before download.

Release verification exercised CSV, XLSX, JSON, and YAML comparison/export flows in stable Chrome and Edge and observed no unexpected external request, non-GET request, or source-file request in those tests.

## Comparison behavior

V0.1 uses strict, type-sensitive semantics. Missing values, `null`, empty strings, whitespace, number/string differences, case changes, booleans, and ordered arrays remain meaningful. Row order and object property order do not change the logical comparison result.

## Tested browsers and range

Automated release evidence was gathered on hosted Windows Server 2025 runners with Google Chrome `151.0.7922.109` and Microsoft Edge `151.0.4129.72`.

The benchmark matrix successfully verified:

- CSV through 100,000 records / 6 fields
- a wider CSV case at 10,000 records / 20 fields
- JSON, YAML, and XLSX at 10,000 records / 6 fields

Each case checked its expected Added, Removed, Changed, and Unchanged counts. Detailed source sizes, environment information, and measured timings are recorded in [V0.1 benchmark results](V0.1_BENCHMARK_RESULTS.md).

These results are tested-range evidence, not a maximum-size guarantee. The automated Windows browser evidence was gathered on hosted runners rather than a physical end-user desktop.

## Known limitations

- Single-field matching keys only; no composite keys.
- No accounts, collaboration, backend comparison service, cloud source/result storage, scheduled comparisons, database/Dataverse connectors, migration execution, ETL, or AI matching.
- Browser memory and format overhead affect practical capacity.
- The release benchmark did not yield a usable browser heap-memory figure, so no memory number is published.
- The production build currently emits a non-blocking Vite large-main-chunk warning; the release process does not suppress it.
