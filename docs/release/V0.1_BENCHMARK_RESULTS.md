# DiffLens v0.1.0 Benchmark Results

Status: **release-candidate benchmark evidence recorded**.

These measurements come from the controlled P08 release-verification workflow on 2026-08-16. They are evidence for the tested range, not a theoretical or guaranteed maximum. Timings on other machines will vary with browser version, CPU, memory, source format, record width, and change rate.

## Environment

Both browser jobs used Microsoft Windows Server 2025 (`10.0.26100`), Node.js `24.19.0`, pnpm `11.17.0`, and the production Vite build.

| Browser | Version | CPU | RAM |
| --- | --- | --- | --- |
| Google Chrome | `151.0.7922.109` | AMD EPYC 7763 64-Core Processor | 8,584,425,472 bytes (~8 GiB) |
| Microsoft Edge | `151.0.4129.72` | Intel Xeon Platinum 8573C | 8,584,425,472 bytes (~8 GiB) |

The jobs used hosted Windows runners rather than a physical end-user desktop. Stable Chrome and Edge were exercised directly, not Playwright's bundled Chromium, for release-browser evidence.

## Workload

Every case used deterministic synthetic data and verified the expected Added / Removed / Changed / Unchanged counts before the case could pass.

- change rate: 10%
- churn rate: 1% removed plus 1% added
- CSV tiers: 1,000; 10,000; 50,000; and 100,000 records at 6 fields
- wider CSV tier: 10,000 records at 20 fields
- JSON, YAML, XLSX: 10,000 records at 6 fields

Expected counts were verified as follows:

| Records | Added | Removed | Changed | Unchanged |
| ---: | ---: | ---: | ---: | ---: |
| 1,000 | 10 | 10 | 100 | 890 |
| 10,000 | 100 | 100 | 1,000 | 8,900 |
| 50,000 | 500 | 500 | 5,000 | 44,500 |
| 100,000 | 1,000 | 1,000 | 10,000 | 89,000 |

## Browser memory observation

The browser performance-memory probe did not produce usable serialized heap figures in these jobs, so no browser-memory number is published. This is intentionally reported as unavailable rather than inferred.

## Tested-range guidance

DiffLens v0.1 was successfully exercised in this release environment with approximately **100,000 CSV records / 6 fields** (about **6.55 MB Before and 6.63 MB After**), **10,000 CSV records / 20 fields**, and **10,000-record JSON, YAML, and XLSX** cases. Stable Chrome and Edge produced the expected comparison counts for every case.

Larger or wider files may work, but practical capacity is browser- and format-dependent. These results must not be read as a hard maximum, a service-level target, or a promise that the same timing will reproduce on another computer.

No millisecond threshold from this table is used as a generic CI pass/fail gate.
